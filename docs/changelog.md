# Changelog

The repository-level changelog is maintained in [`CHANGELOG.md`](https://github.com/Gre3nLioN/lidar-camera-calibrator/blob/main/CHANGELOG.md).

Release notes follow [Keep a Changelog](https://keepachangelog.com/) and semantic versioning. Serialized scene-profile compatibility is versioned independently as `lidar-camera-scene/1`.

## Current development release

Version `0.1.0` establishes the generic source contract, canonical MCAP profile, strict lazy reader, arbitrary-camera calibration UI, JSON export/reload, and package-level launch API.
